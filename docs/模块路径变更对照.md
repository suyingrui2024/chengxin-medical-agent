# 模块路径变更对照

2026-11 的内核分组把 59 个顶层扁平模块并入了七个包（见 [架构分层规则](架构分层规则.md) §9），
顶层现在只剩 `__init__.py`、`cli.py`、`desktop_service.py`。

`docs/` 下多份设计文档写于分组之前，正文里的 `src/medagent/xxx.py` 多数已不在原处。
**那些文档保留原文不改**——它们记录的是当时的设计决定，改写路径会把"当时决定的是什么"
和"现在长什么样"混在一起。这张表负责把读者带到当前位置。

## 前端资源目录（2026-11）

`web/` 从 55 项平铺改成按种类分目录。静态处理器原先只服务顶层文件名，这就是它当年平铺的原因；
现在支持子目录，路径逐段校验，`..`、点开头、`.py` 一律 404。

| 旧路径 | 现在的位置 |
| --- | --- |
| `src/medagent/web/*.css` | `src/medagent/web/css/` |
| `src/medagent/web/*.js` | `src/medagent/web/js/` |
| `src/medagent/web/*.otf`、`fonts-OFL.txt`、`font-sources.json` | `src/medagent/web/assets/fonts/` |
| `src/medagent/web/brand.png` | `src/medagent/web/assets/brand.png` |

| `execution-<part>-ui.js` | `execution-ui-<part>.js` |
| `patient-records-{core,detail,primitives}.js` | `patient-records-ui-{core,detail,primitives}.js` |

图示 URL 也跟着变：`/body-location.svg` → `/assets/illustrations/body-location.svg`，能力包 `packs/*.json`
的 `asset`／`step_assets` 字段同步更新，注册表校验从"根目录下单个 `.svg`"放宽为"若干小写路径段 + `.svg`"。

## 两处容易找错的地方

- **`agent.py` 不是 `server/agent.py`**。旧 `agent.py` 是模型驱动的医疗工具循环
  （`AdaptiveConsultationEngine`），现在在 `consultation/agent/`；
  `server/agent.py` 是 HTTP 处理器 mixin，两者无关。
- **`consultation.py` 不是 `server/consultation.py`**。旧 `consultation.py` 是会谈状态操作与
  离线演示，现在是 `consultation/` 包；`server/consultation.py` 是它的 HTTP 层。

## 七个包各管什么

| 包 | 职责 |
| --- | --- |
| `core/` | 共享词汇与底层原语（domain、events、text_match、phase_graph…） |
| `guards/` | 安全与证据校验 |
| `dialogue/` | 回合级用户交互（任务、位置、观察、问题） |
| `clinical/` | 临床推理与知识 |
| `reports/` | 对外产出（报告、教育、衔接、交接） |
| `review/` | 事后复核与发布核算 |
| `infra/` | 基础设施（后端、进程、平台、配置、插件、会话、图像） |

完整清单见 [架构分层规则](架构分层规则.md) §9。
