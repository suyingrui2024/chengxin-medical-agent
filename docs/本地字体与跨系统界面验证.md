# 本地字体与跨系统界面验证

目标版本：0.11.17。此次只调整字体资产、加载、桌面启动页与验证工具；问诊问题、医学规则、工具策略和模型提示沿用原版本。

## 实际发现

0.11.16在本机Ubuntu的隔离用户环境通过了流程检查，但仍使用本机系统库和字体。进一步用官方Debian 12镜像的独立系统文件、Python 3.11和GTK/NSS运行时启动相同程序时，完整演示问诊能够结束，中文却显示为方框。系统字体对当次页面246个汉字均没有覆盖；该次16项检查中，字形检查失败，其余15项通过。

这是已复现的显示依赖缺口。已有流程测试证明状态和操作链路，不证明文字实际具有可用字形。原失败、镜像摘要和包清单随本版归档保存，不覆盖0.11.16已有记录。

## 随包字体

页面和原生启动页共用`fonts.css`，使用本地Noto Sans CJK SC与Noto Serif CJK SC Regular原始文件。字体来自固定上游提交，字节未改动、未裁剪，版权、版本、大小及SHA256记录在`font-sources.json`，OFL 1.1全文随包提供，见[第三方说明](../THIRD_PARTY_NOTICES.md)。

正文、标题与等宽代码分别使用明确的CSS字体族，范围限于CJK字符及标点，保留既有拉丁文字的字体选择。页面预加载本地字体，字体加载不请求CDN。启动页的CSP仅补充同源字体许可。两个文件合计40,980,444字节，约39.1MiB；新增资产会增加交付包体积。

HTTP页面继续通过现有根目录静态资源路由读取字体；无需开放任意目录访问。`web/*`包数据规则同时包含字体、来源记录与许可证。没有新增模型调用、临床能力或插件代码权限。

## 图示内部的标签

页面字体补齐后的首次复验，正文与标题通过字形门，但测温SVG中的文字仍显示方框；该报告保留为仅覆盖页面的候选结果。SVG作为图片加载时不共享父页面字体，因此单独处理图示标签。

定位图的原始文字图保存在`assets/illustrations/`。开发工具`outline_illustration_labels.py`使用同一原始字体，将定位图标签生成为矢量轮廓。腋温图已改为不含图内文字的中性局部矢量图，操作标签由可访问的 HTML 步骤提供；工具会校验其三个语义分组。`illustration-labels.json`记录两种素材的来源、字体及输出摘要；字体文件本身未改。最终图片不需要系统字体或外部字体请求。

修改源图后生成并核对（仅开发时需要fontTools，已验证4.25.0）：

```bash
python3 -B scripts/outline_illustration_labels.py
python3 -B scripts/outline_illustration_labels.py --check
```

图示验收还需逐图查看实际截图，并检查定位图标签与腋温图的三个语义分组全部保留、没有绘制用text／tspan／foreignObject节点、引用均为本地矢量。语义和操作正确性仍需临床审核；生成轮廓不增加这类有效性证据。

## 验证方法

`check-bundled-fonts.mjs`从当前界面提取实际汉字，读取正文、标题与pre元素的实际计算后字体链，分别加载并检查（不强制指定已知可用字体来代替界面规则）。除`document.fonts`加载状态外，通过Chromium CDP读取实际渲染字体的PostScript名称、自定义字体标记和字形数，拒绝系统字体回退。只看到CSS声明或DOM文本存在不足以通过。

另一次补验发现公式、事件和原始记录的等宽规则绕过了本地字体。已统一到共享的`--mono`变量，并覆盖pre／code／kbd／samp；三条字体链都使用同一批实际页面汉字检查，失败记录保留。中文用本地字形，拉丁代码仍保留等宽显示。

原生检查覆盖启动中的文件页面与服务就绪后的HTTP患者页面。隔离环境探针可使用独立系统文件，并在没有系统中文字体、没有外网、没有开发目录或`.env`的条件下完成问诊、图示、输入纠错和摘要确认。

```bash
# 源码原生字体检查
DISPLAY=:1 XAUTHORITY=/run/user/1000/gdm/Xauthority \
  npx playwright test --config playwright.desktop.config.mjs tests/desktop/fonts.spec.mjs

# 使用已准备的独立系统文件；输出目录须全新
DISPLAY=:1 XAUTHORITY=/run/user/1000/gdm/Xauthority \
  python3 -B scripts/verify_clean_desktop.py \
  --package dist/desktop/Chengxin-0.11.17-linux-x64 \
  --rootfs .runtime/debian-environment-20261017/rootfs \
  --check-bundled-chinese-fonts \
  --output-directory .runtime/bundled-fonts-fresh
```

`--check-chinese-fonts`检查系统字体覆盖；`--check-bundled-chinese-fonts`检查应用字体的实际渲染，两者用途不同。独立系统文件需自行按归档的镜像锁和依赖记录准备，不会自动安装到宿主机。仍需要系统Python、Linux图形库和图形会话；DSH另需Node与bubblewrap。

测试使用同一宿主内核和X11显示服务，自动化含`--no-sandbox`，不能当作独立物理机器、Chromium进程沙箱或所有Unicode字符的验证。临床审核和患者理解研究仍缺资源，不能用本次字形与布局检查替代。最终源码、截图、失败与复验范围见[0.11.17归档](evaluations/2026-10-17/v0.11.17/README.md)。
