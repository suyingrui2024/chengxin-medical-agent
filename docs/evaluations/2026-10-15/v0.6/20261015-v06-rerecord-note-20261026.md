## 与旧序列相比的题序变化（新序列真实走过的顺序）

consult_for → sex → age → chief_complaint → emergency_screen →
图示任务（腋温，引擎从主诉自动同步）→ onset → trajectory →
severity → associated_symptoms → resp_breathing → resp_cough_details
→ resp_intake → medications_taken → allergies → relevant_history →
（空回复 service_error）→ 重试 → patient_goal → 摘要 → 确认关闭。
另有两处如实记录的取舍：

- reported_temperature 为非阻塞题，主诉含“发烧”故进入候选，
  但 harness 答案表无此键（授权只补 sex，不得另加键）；体温任务
  轮患者已报出“腋温 38.2℃”，后端在该轮直接记录
  reported_temperature（值“腋温 38.2℃”，引文为任务回答原文），
  使其不再进入后续候选。体温测量事实 temperature_c 仍由任务流
  单独记录，两者不冲突。
- relevant_history 的 absent 断言 value 必须为 null（旧恢复段第 1
  条用文本值、第 2 条用 null 正是同一校验的一驳一改）；新序列
  恢复段直接使用 null 值，避免重问循环。
