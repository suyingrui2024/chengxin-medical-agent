## 阶段 1 · 分诊单次计算与三层化

### 实现

- 红旗定义数据化：`src/medagent/content/red_flags.json`（6 条急症红旗，
  含短语层、转述模式层、组合规则层与否定豁免声明），
  `EMERGENCY_RULES` 改为由该文件派生，消除代码常量与数据两套来源。
- 新增 `src/medagent/red_flags.py`：分层扫描器
  （`rule_phrase` / `semantic_pattern` / `semantic_combo` / `provider`），
  其中短语层的否定判定与历史实现逐字一致；模式/组合层使用子句级否定
  抑制，并对"反应都没有"这类否定词本身即症状的模式提供豁免通道；
  胸痛组合规则带排除词（血压、气压、胸围等测量语境）。
- `TriageService` 改造：`scan_text` 纯函数化并按文本记忆化——同一轮内
  consultation 与 agent 两处共 9 个调用点对同一文本只计算一次；
  新增 `scan_detailed` 暴露分层命中明细；`assess` 逻辑与对外语义不变；
  预留 `SemanticProvider` 注入点，约定 provider 只能新增命中、且证据
  必须是原文子串（阶段 3 的推理复核层将经此接入）。
- 新增 `scripts/evaluate_red_flags.py` 与 `tests/test_triage_layered.py`
  （13 个用例，含语料门测试）。

### 诚实边界与暂缓项

- 探针集在第一轮迭代中被用于定位漏检模式，此后不再是完全留出集；
  "首次接触 0.667"才是无偏的泛化估计。真正的泛化能力需靠后续临床语料
  （设计文档 5.2）与阶段 3 的语义/推理层建立，本阶段数字只证明：
  确定性 + 精选模式层可以把已知说法空间内的漏检清零且不引入误报。
- 设计 5.4 的"影子运行后切换"本阶段以直接切换替代，理由：短语层行为
  逐字保留、新增层**单调递增**（只能新增触发、不能撤销任何既有急症
  结论）、行为基线全绿。推理复核层（阶段 3）上线时仍按影子→灰度执行。
- `TurnContext` 对象随阶段 2 管线一并落地（单次计算目标已由记忆化达成）。
- 全部语料为工程语料（unreviewed），不构成临床验证，符合仓库既有评测
  合同的口径。
