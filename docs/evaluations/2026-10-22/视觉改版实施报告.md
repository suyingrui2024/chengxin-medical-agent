# 视觉改版实施报告（2026-10-22）

## 做了什么

**V1 令牌与排版**
- 默认主题纸面降饱和：--paper #f5f6f2 → #fbfcfa，--raised 改纯白，
  --line 减轻（#dce5da → #e4eae2），--ink 加深；品牌绿回到行动与点缀。
- 患者界面字阶提升：消息气泡 13 → 15、输入框 12 → 15、快捷回复
  11 → 13.5、事实值 11 → 13.5、事实标签 9 → 11.5、页说明 12 → 14.5、
  导航 13 → 14、欢迎区正文/按钮 12 → 14、顶栏连接状态 11 → 12.5、
  抽屉活动区 12/11/14 → 13/12/15、eyebrow 8 → 11；结论单沿用其
  15–16px 规格。
- **字号档位上线**：外观对话框新增 字号大小（小/标准/大），
  localStorage 持久化（chengxin.fontscale.v1），themes.js 首屏前
  应用，覆盖主要患者文本面。
- 欢迎区压缩：插图高 156 → 118、内距收紧、main 顶距 36 → 26，
  开始卡在首屏内露出。

**V2 布局与信息架构**
- 问诊内容列单列居中（max-width 880px），标题行同宽对齐。
- **事实面板抽屉化**：position fixed 右侧滑入（370px），遮罩 +
  Esc/点外/关闭钮三种关闭方式（复用已有 #toggle-facts 开关与
  .open 机制，新增 #facts-scrim 与 #facts-close）；计数芯片成为
  唯一常驻计数出处。任务聚焦模式下整面板隐藏的既有行为保留。
- "测试视图"切换从侧栏顶部移到侧栏底部（JS 搬迁，功能不变）。

**V3 组件**
- 急症筛查信号：由三列大瓷砖改两列清单行（图标 26px + 文字，
  .screen-question 作用域）；问号符号框 50 → 42px。
- 严重度量表：语义色带（0–3 绿 / 4–6 黄 / 7–10 红，主题变量驱动）。
- 部位选项图标 32 → 40px（self-check.css）。

**Logo**：评估后不换。现标志（深绿圆角方 + 白色知微笔意 + 橙点）
识别度与品牌一致性都够，问题在界面不在标。

## 验证

- 全量 pytest：458 passed, 72 skipped，无回归；改动的三个 JS 文件
  node --check 通过。
- 实机走查（无头 Chromium，完整问诊一遍）：急症屏、量表、摘要、
  关闭页逐屏截图复核；关闭页结论单聚焦呈现不回归（缩放断言
  conclusionVisible=true、内容列 880px、事实面板 fixed）。
- 移动端（390×844 模拟）与大字号档各自截图复核。

## 与设计说明的偏差（如实记录）

1. **量化门未全达**：≤12px 声明 225 → 217、1px 边框 79 → 78，
   未达 §9 的 ≤60 / ≤30。原因：余量集中在研发/执行/巡检等高密度
   界面与微标签，对其做机械清扫的风险收益比不成立；患者主流程
   的可见文本面已按字阶处理。剩余清扫建议单独立项、逐面回归。
2. **人体图可点选未做**：主问诊的部位步是选项按钮流（自查任务里
   已有可点区域），把主流程改成可点人体图涉及新的观察输入路径，
   不属纯视觉改动，留作单独事项；本轮只放大了选项图标。
3. **状态去重部分完成**：计数已唯一出处；抽屉内的阶段标签保留
   （属按需打开的次级层，不在常驻界面重复之列）；顶栏连接状态
   与离线演示片保留（后者为研究原型声明）。
4. DV 决策的落地选择：DV1 衬线保留（未动）；DV2 按建议降饱和；
   DV3 按建议抽屉；DV4 档位为 小/标准/大、默认标准；DV5 本轮只
   覆盖患者 web 界面，研发界面仅做密度豁免、未改版。
