# 事实断言与否定证据校验

0.11.3 修复模型提议中的不确定信息被记录为“明确没有”的问题。旧校验仅要求阴性引文中出现“没／无／不／否认”之一，因而“过敏不知道”“是否用过药不确定”都可能通过。演示解析与真实模型提议共用的来源、证据、状态和整批原子写入原则继续保留。

## 患者可见行为

未知内容仍显示在摘要的待确认区域，保留实际原话与补充入口。模型提出错误否认时，控制器拒绝整批提议，将具体错误作为观察返回，允许模型修正；未接受的提议不产生事实记录。患者不会被要求阅读工具参数或错误堆栈。不能修正时保持已有状态和未完成流程，不虚构成功。

带“好像”“应该”等限定的病史更正保留未知；明确的“没有”仍可作为否认。模型可保留完整限定的文本叙述，但不能从引文中删去不确定限定后写成已确认结论。已有明确否认不会因为另一分句中的其他病史未知而自动变成未知。

## 校验范围

`assertion_evidence.py` 提供确定性证据检查；`agent_tools.py` 在事实写入前执行它，`interpreter.py` 对病史、筛查及直接更正识别不确定表达。医疗决策事件的策略版本为`medical-tools-v0.11.3`。

| 原话与提议 | 处理 |
| --- | --- |
| “过敏不知道”提议`absent/null` | 拒绝，保留未知或澄清 |
| “我记不清有没有用药”仅引用“没有用药” | 拒绝，不能删去同分句的限定 |
| “没有用药，具体不确定”仅引用前半句 | 拒绝，检查紧邻的纯限定语 |
| “过敏不清楚，没有用药”分别记录两项 | 过敏未知；明确用药否认可以接受 |
| 同一短引文出现多次，其中一次带不确定限定 | 短引文有歧义，需附完整范围 |
| “有没有用药”“无所谓用药”“没有必要用药” | 不能当作明确用药否认 |
| “不是没有用药” | 不能把另一层否定解释成没有用药 |
| 原话不确定，却用`present`写“没有过敏” | 拒绝文本中的未确认否认 |
| “用过药物甲，用量不清楚”规范化为“用过药物甲” | 拒绝遗漏限定，保留原话或未知 |

否定线索不再接受单个“不”。含不确定词的引文不能作为`absent`；未知提议也必须实际引用不确定表达，未提及仍属于缺失。病史类`present`文本若包含明确否定，同样校验其否定证据；原引文的不确定限定不能在规范化文本中消失。

分句边界使用中英文逗号、句号、分号、问号、感叹号与换行。检查引文全部出现位置，并检查紧邻的纯限定语，如“具体不确定”。旁边明确命名的其他病史不作为纯限定语。例如“过敏不清楚”不会使另一分句中的“没有用药”失效。

## 验证

新增后端矩阵覆盖四类病史字段、不确定词、截短引文、限定语、重复引文、疑问和非病史否定、文本绕过、原子拒绝与年龄保留，以及直接更正。浏览器与原生桌面使用同一真实服务：本机确定模型先提出错误整批事实，观察拒绝后改为未知，再由真实控制器生成摘要；病史更正保留未知与历史。

真实DSH试验先注入一个明确标注的合成错误提议，再让DeepSeek实际读取拒绝观察并继续决策。第一阶段测试`absent`错误，后续阶段另验证`present`文本绕过。两阶段的提议形式不同，不能比较成自然模型错误率或准确率改善。运行快照、请求数、错误与最终结果保存在[0.11.3归档](evaluations/2026-10-17/v0.11.3/README.md)。

## 限制

这是对已注册事实提议的有限规则校验，不是完整中文医学语义解析器。它不能证明字段归属、跨句否定范围、疾病或药物识别、剂量细项及所有中文表达都正确。一个分句混合多个字段时仍可能需要澄清；不能据此声称完全理解患者原话。

通过词汇保留检查也不证明规范化文本保留了所有医学含义。此版没有新增诊断、处方或临床公式，真实试验只用合成叙述，尚需临床人员标注的病例与目标用户验证。
