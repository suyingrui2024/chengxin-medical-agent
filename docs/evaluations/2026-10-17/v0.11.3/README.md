# 0.11.3：不确定病史不能直接记成明确没有

修复事实提议校验把单个“不”视为阴性证据的问题。新增不确定表达、同分句引文范围、紧邻纯限定语、重复引文、疑问与部分非病史否定检查；病史类`present`文本也不能写入未确认否认，或在规范化时删去引文的不确定限定。错误仍作为观察返回模型修正，整批事实在校验通过前不写入；患者继续使用原有原话卡片与补充入口。

当前桌面包为`dist/desktop/Chengxin-0.11.3-linux-x64/Chengxin`，桌面图标通过原启动脚本打开新版。需保留整个应用目录、系统Python与相应Node环境；当前为Linux x64研究原型。

## 实际缺口与修正

[旧版固定输入探针](absence-evidence-baseline.json)中，“过敏不知道”“是否用过药不确定”以及从“我记不清有没有用药”截取的“没有用药”均能通过阴性校验。[相同十条输入的新版结果](absence-evidence-fixed.json)拒绝七条错误或不充分的否认，保留三条明确否认／其他病史未知的正例。它是固定反例与正例检查，不是临床语言准确率估计。

原始完整控制器缺口另保留在[两字段提议记录](controller-baseline.json)：不确定原文被写成`absent`，没有外部模型调用。第一阶段尚未约束`present`文本时，[冻结旧代码探针](present-text-baseline.json)实际接受“过敏不清楚”作为“没有过敏”的文本证据；[最终相同提议](present-text-fixed.json)已拒绝。

## 真实DSH恢复

[第一阶段](live-round1.json)和[最终阶段](live-round2.json)各5次DeepSeek请求，共10次。每个场景先由评测器注入一个明确标记的合成错误提议，后续真实DSH调用读取实际校验错误并继续决策。第一阶段是`absent`错误；最终阶段另覆盖`present`文本绕过与截短引文。

本人过敏未知与家属用药不确定场景均实际到达摘要，错误提议未产生错误阴性历史，年龄在原子拒绝后保留，另一项明确否认也保留。该试验验证错误观察与修正流程，不估计模型自然错误率，不将注入提议计作模型调用。两阶段提议形式不同，不能比较成准确率提升。

两阶段分别冻结并核对86份医疗运行与评测输入，字节快照在`live-round1-source`和`live-round2-source`。最终控制器另对四组保存记录完成[离线重放](v0113-frozen-replay.json)：共重放10个真实模型决策及4个注入提议，外部调用0；这不计作新真实模型样本。

## 工程验收

逐项结果见[verification.json](verification.json)。最终默认后端262项中209通过、53跳过；再单独运行其中50项SDK／隔离／本地接口检查，50通过。按实际测试身份去重为259通过、3项长时检查本轮未重跑，见[计数核对](v0113-backend-coverage.json)。185／142／605秒长检查保持0.10.6历史证据归属，不算本版通过。

新增9项后端测试、1组界面与1组原生完整流程。最终浏览器28组、源码与打包版各20组原生检查通过，包含实际拒绝、错误观察、修正、摘要、直接更正和历史保留；技术错误不进入患者对话。第一阶段通过后补充了`present`文本校验，因此最终代码重新运行相关默认后端、50项集成、界面与原生检查，未用初阶段结果代替最终代码证据。

新桌面包102份项目文件逐字匹配，544个适用生产依赖版本匹配。这不是完整依赖内容签名审计。最终231份源码、测试、包内元数据和相关文档保存于`snapshot-final`；在未复制`.env`或`node_modules`的新目录实际运行66项患者流程检查，全部通过、无跳过，源码前后保持。两个真实阶段与最终冻结代码的关系均保留，不覆盖旧评分。

构建前核对既有690文件归档和原始环境／候选证明，清理了不再占用的`.runtime/public-transfer/prepared-v5`临时准备副本，保留来源归档、wheel、候选证明和所有旧桌面包。记录见[v0113-disposable-storage-cleanup.json](v0113-disposable-storage-cleanup.json)。

## 冻结复验

在项目根目录执行，目录和输出文件必须未使用；需要Python 3.10+，不读取`.env`，不调用外部模型或下载：

```bash
cp -a docs/evaluations/2026-10-17/v0.11.3/snapshot-final /tmp/chengxin-0113-check
python3 -B docs/evaluations/2026-10-17/v0.11.3/verify.py \
  --project /tmp/chengxin-0113-check --output /tmp/chengxin-0113-check.json
python3 -B docs/evaluations/2026-10-17/v0.11.3/replay.py \
  --project /tmp/chengxin-0113-check --output /tmp/chengxin-0113-replay.json
```

本版仅提供有限的中文断言证据校验，不证明字段归属、跨句范围或所有规范化医学含义都正确。一个分句混合多个字段时仍可能需要澄清；真实试验仅用合成叙述。完整规则与限制见[设计](../../../事实断言与否定证据校验.md)。尚未进行临床有效性验证，也未证明总体达到DSH／Codex能力；整体优化目标保持进行中。
