# 新增公开任务对照

本轮评价发布的0.10.5产品与独立官方DSH SDK路径，在相同公开仓库任务、模型、环境、调用额度和总时限下的表现。任务、评分与顺序分别由 `benchmarks/swe-lite-transfer/selection.json`、`scoring.json` 和冻结报告记录；开始付费调用后不调整产品或评分。

## 固定任务与抽样范围

数据来自已固定哈希的SWE-bench Lite公开TEST分区，共300行；JSON与原始Parquet逐行核对一致。按已有四个环境适配器分层，排除本项目已记录的14个历史实例ID（其中6个在该TEST分区），得到113个符合仓库与排除条件的候选：Matplotlib21、Flask2、Sphinx14、SymPy76。每层排序后用同一个种子2026101605依次洗牌取第一题，不按题目内容、预检难度或模型成功率换题。

| 固定任务 | 仓库 |
| --- | --- |
| matplotlib__matplotlib-25498 | matplotlib/matplotlib |
| pallets__flask-4045 | pallets/flask |
| sphinx-doc__sphinx-8474 | sphinx-doc/sphinx |
| sympy__sympy-20049 | sympy/sympy |

这是对项目已有环境的分层子样本，不是对全部300题的等概率抽样。任务未用于本项目此前记录的夹具与调优，但属于公开历史数据，模型可能已在训练中接触；不能称为无污染保留集。

四题均在付费调用前验证：原始代码暴露全部指定FAIL_TO_PASS缺陷并通过PASS_TO_PASS，上游参考修复通过全部对应节点。四题分别指定1＋69、2＋50、4＋436、4＋9个FAIL_TO_PASS／PASS_TO_PASS标识，映射到实际收集节点保存在预检报告。环境失败不换题；未全部合格时不启动付费对照。

## 两条执行路径

产品经 `ExecutionManager → execution-worker → 官方DSH SDK`；基线直接由 `scripts/execution_test_baseline.mjs` 创建官方SDK，不经过产品管理器、控制插件和完成门。两边固定官方包0.2.0-rc.2、同一配置模型、8192 token输出上限、相同源码与依赖、文件隔离策略及用户任务；每次最多20个实际上游请求、600秒，子任务与辅助搜索共享该额度。

产品保留自己的persona、动态预算、受信计算、交付检查、等待与完成判断；基线保留官方默认persona和工具行为。它们是被评价的产品差异，完整系统提示和工具表并不相同。不得把本轮解释为所有底层条件都相同，或与可操作整台宿主的无限制DSH直接比较。

每题每条路径重复两次，总计16次运行。配对内先后顺序由种子2026101606固定，总硬上限320次实际上游请求；每次转发前记录账本。中断留下的未确认请求仍计入，未能确认进程终止时不能重新启动同一运行。

## 分开的验收维度

主实现判定从冻结源码重建，恢复原测试、配置和依赖，再覆盖候选实现，应用原始上游测试补丁，实际运行全部指定节点。退出码、每节点结果和缺失／跳过均记录；不能只看模型报告或根回合结束。

文件契约与提示共用已有显式定义：受保护文件逐字保留，新增回归只允许直接放在 `regressions/test_*.py`。候选关停后保存实际普通文件字节、删除项和链接文本，再隔离重建；宿主不跟随候选链接读取目标。候选自己的新增测试另行运行，要求每个新增文件确有测试收集且全部通过，防止实现通过上游检查却附带错误测试。

同时报告实现验收、文件约束、新增测试、实际收尾、上游请求数与耗时。联合交付要求这些检查共同通过。没有新增测试时标记不适用，不声称具备生成测试覆盖率。局部代码正确与回合正常收尾不能互相替代。

评分器先用本地确定模型验证：参考修复在两条路径均通过；未修复种子虽正常结束仍被拒绝；参考实现加错误新增测试被识别为“实现通过、交付失败”。这些是零外部调用的驱动与评分验证，不进入真实模型成绩。

## 边界与记录

不向候选挂载隐藏检查器或参考补丁。禁止检索上游答案写入共同任务，但终端网络没有硬拦截；工具轨迹与网络命令仍需审阅，不能把没有看到搜索工具当成网络隔离证明。环境使用固定依赖和历史解释器，Matplotlib保留基础提交的Python实现，并复用记录哈希的预编译本机扩展（没有从本题源码完整构建wheel）；这不是官方SWE-bench容器评分。

各轮源码、任务、评分、请求账本、候选覆盖层和独立检查输出保留，失败与未评估项不能删除或换题。该四题与重复次数只能支持当前条件下的有限结论，不能证明整体达到DSH／Codex，也不涉及医疗有效性或患者理解验证。运行后的313次请求、两边均无Git历史的条件、规格差异和全部16份候选独立重验见[冻结结果](evaluations/2026-10-16/v0.10.5-transfer/README.md)；本设计的调用前版本也在该目录保留。

```bash
python3 scripts/prepare_public_transfer.py

```
