三轮使用同一已知合成问题，最后一轮还改变了明确契约。不能据请求差异宣称整体能力提升，不能报告为独立保留集成绩、DSH 全面对照或临床验证。

`runs/*/online-snapshot` 是每轮调用前冻结版本，均与原报告源码哈希核对一致；`snapshot-final` 为最终运行代码、测试及相关工具。两次测试 fixture 失败日志保留：Python 首轮误读已有回执字段；原生首轮故障注入绕过正常 Electron 请求层，未实现预期提交，之后改为正常提交完成后丢弃响应。生产中没有测试路径开关。
