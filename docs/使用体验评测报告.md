## 二、逐环节评价

### 开场（02-蓝-opening）

三位一体的咨询对象卡（我自己/孩子/其他家人）清晰；"紧急求助"**常驻**
右上角，任何时刻可点。好。

### 安全筛查（09 / 11-蓝-safety-screen）

主诉说完立刻进入红旗筛查：六个危险信号卡 + "有任何一项/都没有/不确定"。
"请逐项查看；有任何一项或不确定，都请如实选择"——明确告知不确定也
要选，比让患者猜好。**这是全产品最关键的一道闸，呈现是合格的。**

### 病史问诊（14 / 17 / 20 / 23）

每题一屏、选项带图标、可展开对话记录核对原话。节奏好，无压迫感。

### 图示定位任务（32 / 35-蓝-location-\*）

人体图带"右/左"标注与"虚线范围仅表示所选大部位；左右以患者自己为准"
的说明——**把"左右以患者为准"写出来是对的**。选完部位后确认按钮
直接变成「**记录：头/面部**」——所见即所记，防误触设计好。

### 摘要核对（50-蓝-summary-sheet）

结构完整："待你核对"徽章、"未确认"与已确认的区分、红旗框常驻、
每条事实带"更正"与"原话与来源"折叠。底部明确
**"系统没有据此作出诊断；请结合症状变化和专业医疗评估决定下一步"**。

### 结论单（53-蓝-after-confirm）

整体判断 → 下一步（可在家观察 + 建议科室：全科医疗）→
就诊时请告诉医生（患者原话）→ 现在能做的事 ·4 → 红旗 ·4 →
接下来 ·2（**"我会在 72 小时后来确认"** 的随访安排）→
"先别太焦虑，按上面的安排来就好" → 免责声明。完整、克制、有人味。

### 急症路径（62-红-escalation）

主诉说完**一轮直达**"立即急救"卡：现在拨打 120 按钮、
"先别慌，按下面的步骤来就可以"的安定语气、已确认情况复述、
"查看触发原因"可展开、"不要继续等待本次对话"。**合格。**

### 代答路径（黄）

"孩子"入口 → 性别 → 年龄 → 主诉 → 一直到体温测量图示任务
（87-黄-severity 之后转入 105-黄-end-state：测一次腋下体温，
准备/放置/读数三步图示 + "没有体温计 / 做不到/不舒服 / 暂时跳过"
三个体面的退出按钮）。代答全程不需要家长冒充本人身份。好。

### 坏路径

- 空消息：400 `invalid_message`「消息不能为空」✓
- 不存在的会话：404 `session_not_found` ✓
- 异常输入后的恢复文案："我没能确认年龄。请写成'8个月'或'32岁'
  这样的格式。"——**给格式示例的错误恢复，教科书级**（114 图）
- 双击发送：未见可见的重复消息（发送中按钮禁用生效）

## 六、第三轮：像患者一样连续使用（2026-11-05）

前两轮是"把每个环节走到"；这一轮换了个问法：**一个患者连着用下去，会不会撞上
说不通的地方**。所以重点不在功能是否齐全，而在改口、反悔、换人、关了再回来
这些真实动作上。

### 6.1 方法

13 组、63 项断言、591 次真实点击与输入、159 张截图、23 份逐轮对话全文，全部在
[`evaluations/2026-11-04-usage-review-r3/`](evaluations/2026-11-04-usage-review-r3/)。

- 三个画像 + 一个"界面"画像（主题/窄屏/错误态）+ 一个"补拍"会话：
  🔵 32 岁后脑勺胀痛（主流程、更正、改主诉）、🔴 58 岁胸痛（澄清、直达急救、8 分延迟门）、
  🟡 3 岁孩子发烧（代答、测量、重复测量、报告）。
- 每一步都是**真实点击与打字**；API 只用来读 `snapshot` 做断言。
- 每张截图按"人员+阶段+修订+题号+可见按钮+打开的弹层"做指纹去重，
  同屏重复 222 次被跳过（上一轮 73 张里 25 张是重复图）。
- 断言结果写进 [`findings-r3.json`](evaluations/2026-11-04-usage-review-r3/findings-r3.json)，
  报告里每条结论都能按"编号 → 图号"回放到同一屏。

局限：demo 是确定性引擎，我测的是"这条路径上的语言与状态"，不是真实模型的
问诊质量；一处演示环境的可达性缺口写在 6.6。

### 6.2 三段旅程

**🔵 我说错了，想改一句话。** 前四题很顺，说到"后脑勺胀痛两天"之后，它请我
在人体图上点一下位置——点完大部位，主按钮直接变成「记录：头/面部」，所见即所记，
这一步让人放心。真正的问题出在我想改：我发现自己把疼痛说轻了，可问题卡上没有
任何"改一下"的入口，得先想到右上角那个「已记录信息 9」的抽屉。抽屉打开了，
里面写着 `sex / male`——一行英文键名和英文值，夹在"咨询对象 本人"中间格外刺眼。
改完主诉更意外：它把我答过的开始时间、变化趋势、影响程度**悄悄撤回**，
重新问了一遍急症筛查，唯一的解释是一句 4.5 秒就消失的提示，还写着"摘要已重新整理"
——那时候根本还没有摘要。我不确定自己的回答是丢了还是被重问了。

**🔴 一句"胸口有点疼"被反问了四个问题。** 我按最朴素的说法说"胸口有点疼"，
它没有立刻喊急救，而是先问：什么样的感觉、有没有放射、有没有出汗、持续多久。
这段语气是克制的，也给了两个明确选项；我点"没有"，它就把问诊继续下去。
另开一次会话，我改说"胸口像压了块大石头，喘不上气，一直出冷汗"，**一轮**就给出
120 与"不要自己开车"。这个反差是合理的——但 8 分疼痛那次不是：我疼到 8 分，
它继续问"还有哪些同时出现的不舒服"，没有一句话告诉我"其实现在就可以去"。

**🟡 替孩子问，最怕它没在听。** 我说孩子 38 度 5，它先承认"你刚才说的体温已经
记下了，标记为自述"，再请我实测——这句衔接把"为什么还要测"讲清楚了。测完 38.2，

### 6.4 这一轮让我放心的

- **急症的两种速度都对**：明确的压榨样胸痛 + 喘不上气 + 冷汗，一轮直达 120；
