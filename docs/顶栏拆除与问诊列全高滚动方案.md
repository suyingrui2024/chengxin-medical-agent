# 顶栏拆除与问诊列全高滚动方案

版本：v1.0（2026-10-22）· 状态：已实施（合并 a55bf13）
缘起：负责人以 Muse 对话页为参照提出——右侧只留会滚动的对话
与吸底输入框，"患者服务 / 问诊"一行可以去掉。本方案落地。

## 判断

顶栏一行三样东西全是重复或错位：面包屑与侧栏高亮、页面标题
三重陈述同一事实；连接状态正常时是废话、异常时才重要；患者
模式的"离线演示"标与页脚注脚重复。研发模式的后端标是按钮
（点开模型配置弹窗），是真功能，需要新家。桌面端已核实：
顶栏不承担 Electron 窗口拖拽（无 app-region），可安全拆除。

## 改法

1. **顶栏桌面端整行删除**；DOM 迁移三件：
   - `#backend-pill`（研发模式）移入侧栏底部、设置项之上，
     沿用 developer-only 显隐，点击行为不变（打开模型配置）。
   - `#patient-mode-label`（患者模式"离线演示"标）删除，
     声明由页脚注脚承担（已存在同文）。
   - `#connection-status` 移入新增的列顶提示条
     `#connection-alert`（位于 main 首位）：默认隐藏，init 成功
     保持隐藏，失败时显示"服务未连接"（原有 toast 保留）。
     常驻指示只剩侧栏"本机数据"状态点。
   - `#mobile-menu` 与 `#page-title` 保留在顶栏内：移动端
     （≤980px）顶栏以细条形态仅显示这两样（菜单钮 + 页标题），
     桌面端顶栏 display:none。
2. **问诊列全高**：.app-shell 改 height:100dvh；.workspace 改
   纵向 flex 且 overflow:hidden；main 改 flex:1 + overflow-y:
   auto（文档型页面照常整页滚）；#view-consultation.active 改
   flex 纵列 height:100%，.conversation-panel 的 height:clamp
   改 flex:1 + min-height:0，内部 .conversation-scroll 继续自
   滚，输入区吸底。各断点与 has-session / task-focused 变体里
   的 panel 定高逐条改为 flex 等价；聚焦任务（部位图等）的
   分屏规则单独核对，不顺手改其内部布局。
3. **其他页面**：大标题即第一行（page-heading 结构不变）；
   设置/档案/记录/研发视图随 main 滚动，行为不变。

## 风险与验收

- 风险集中在布局模型切换：定高规则散布 8 处（基础 + 断点 +
  状态变体），逐条转换后以截图矩阵验收：问诊（未开始/进行中/
  聚焦任务/关闭）×（1440/1100/390），档案、设置、研发各一，
  断开连接时提示条一张（停服后截）。
- 回归：pytest 全量；开始问诊/发送/关闭全程实走一遍（上轮
  教训：DOM 迁移后必须真跑流程，不只看静态页）。
- 纯前端，独立分支，可整体回退。
