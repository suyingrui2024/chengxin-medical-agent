# 11 · SOFA 器官衰竭评分

**注册 id**：`calculate.sofa`　**版本**：1.0.0　**内容哈希**：`bbc07f7af0ebf7a7`

**受众**：仅医生　**覆盖形态**：量表 · 仅医生 · 分段查表

## 它是什么

序贯器官衰竭评分（6 个系统，0–24 分）。

## 范围与限制

只按公开量表规则计分与分档，不判断是否患病，不给治疗或用药建议。

### 条目与计分

| # | 条目 | 选项（分值） |
| --- | --- | --- |
| 1 | 氧合指数 PaO2/FiO2 | 低于 100 → 4 分；100 至 200（含 100） → 3 分；200 至 300（含 200） → 2 分；300 至 400（含 300） → 1 分；400 及以上 → 0 分 |
| 2 | 血小板 | 低于 20 → 4 分；20 至 50（含 20） → 3 分；50 至 100（含 50） → 2 分；100 至 150（含 100） → 1 分；150 及以上 → 0 分 |
| 3 | 总胆红素 | 低于 20 → 0 分；20 至 33（含 20） → 1 分；33 至 102（含 33） → 2 分；102 至 204（含 102） → 3 分；204 及以上 → 4 分 |
| 4 | 循环 | 平均动脉压 70 及以上（0 分） ／ 平均动脉压低于 70（1 分） ／ 多巴胺不超过 5 或任意剂量多巴酚丁胺（2 分） ／ 多巴胺大于 5 或去甲肾上腺素不超过 0.1（3 分） ／ 多巴胺大于 15 或去甲肾上腺素大于 0.1（4 分） |
| 5 | 格拉斯哥昏迷评分 | 低于 6 → 4 分；6 至 10（含 6） → 3 分；10 至 13（含 10） → 2 分；13 至 15（含 13） → 1 分；15 及以上 → 0 分 |
| 6 | 血肌酐 | 低于 110 → 0 分；110 至 171（含 110） → 1 分；171 至 300（含 171） → 2 分；300 至 440（含 300） → 3 分；440 及以上 → 4 分 |

**计分规则**：各条目得分相加。总分范围 0–24 分。

### 分档

| 区间 | 分级词 |
| --- | --- |
| 0–1 分 | 低 |
| 2–3 分 | 中 |
| 4–7 分 | 高 |
| 8–24 分 | 很高 |
