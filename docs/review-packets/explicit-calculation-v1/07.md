# 07 · BMI 体质指数

**注册 id**：`calculate.bmi`　**版本**：1.0.0　**内容哈希**：`9d5a102f05b3c0da`

**受众**：患者可自评　**覆盖形态**：公式 · 患者可用

## 它是什么

按身高体重计算体质指数（kg/m²），仅作记录与参考，不构成肥胖诊断。

## 范围与限制

只按标注来源做算术计算，不评价结果、不作诊断、不给处理建议。

> 仅成人；孕妇、儿童、运动员不适用。

### 输入与输出

| 输入 | 单位 | 可填范围 |
| --- | --- | --- |
| 身高 | cm | 50–250 |
| 体重 | kg | 2–400 |

**计算式**：体重（kg）除以身高（m）的平方

**来源编号**：WHO-BMI-2004

**已知限制**：

- 仅适用于成人；孕妇、运动员、儿童与老年人不适用。
- 不区分肌肉与脂肪，不构成肥胖诊断。

**输出**：体质指数，单位 kg/m²，保留 1 位小数，可接受范围 5–200。

### 分档

| 区间 | 分级词 |
| --- | --- |
| 低于 18.5 kg/m² | 偏低 |
| 18.5 至 24 kg/m²（含 18.5） | 正常范围 |
| 24 至 28 kg/m²（含 24） | 偏高 |
| 28 kg/m² 及以上 | 明显偏高 |

## 来源

- WHO BMI classification
- WHO-BMI-2004：成人 BMI 分类（低于18.5 偏低 / 18.5–23.9 正常 / 24–27.9 偏高 / ≥28 明显偏高，采用中国成人标准）
- https://www.who.int/news-room/fact-sheets/detail/obesity-and-overweight（访问于 2026-10-27）
