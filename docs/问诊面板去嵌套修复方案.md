# 问诊面板去嵌套修复方案

版本：v1.0（2026-10-22）· 状态：按此实施
缘起：产品负责人实机截图指出——右侧问诊区像"界面里嵌了个界面"，
同一套信息显示了两遍。《视觉改版设计说明》P4「状态只说一次」
未贯彻到问诊面板，本方案补拆。

## 问题（已对代码核实）

外层外壳已经提供：侧栏品牌、顶栏面包屑 + 连接状态 + 后端标
（DSH 问诊）、页面标题（本次问诊）。问诊面板 `.conversation-panel`
内部又自带一整套：

| 内层元素 | 与谁重复 |
|---|---|
| 卡头头像 + "知微健康助手" | 侧栏品牌（第三次出现） |
| 副标题 #conversation-subtitle（"DSH 问诊 · 本次会谈"等） | 顶栏后端标 |
| 阶段标 #conversation-status（如"明确问题"） | 事实抽屉内阶段标；且问题区已有"当前这一步" |
| #review-status 复核标 | 同上，属状态陈列 |
| 卡头下色带 #task-focus-bar | 与卡头叠成第二条标题栏 |
| 面板边框/底色/阴影 + 圆角 | 与页面底色叠成"卡中卡"的框感 |

后果：一个问题要穿过 页面标题 → 卡头 → 色带 三层横条才可见。

## 拆什么、留什么

**删**：整个 .conversation-header（品牌区、副标题、阶段标、复核标）
及其在 app.js 中的写入点（#conversation-status ×2、#review-status
一块、#conversation-subtitle ×2）；面板的边框、底色、阴影、圆角。
**移**：#urgent-help「紧急求助」按钮移到页面标题行，与"已记录
信息"并排（常驻可见性不降，样式沿用其警示色）；其 disabled /
hidden / 点击逻辑按 id 不变。
**瘦身**：#task-focus-bar 去色带底色与边框，降为一行小字
（"当前这一步" · 右侧"展开对话记录"文字链），功能不变。
**留**：输入区（composer）自有边框与圆角保留——去框之后它就是
悬浮在纸面上的输入条；消息区头像保留（对话归属需要）；事实抽屉
内的阶段标保留（按需打开的次级层，不算常驻重复）。

## 实施与验收

- 改动面：index.html（删卡头、移按钮）、app.js（删 5 处写入）、
  styles.css（面板去框、聚焦条瘦身、标题行容纳双按钮、清理卡头
  死样式）。无后端、无数据结构变化。
- 回归点：#urgent-help 的显隐/禁用由后端 reply 驱动，移动后逐项
  复核（未开始禁用、进行中可用、关闭后隐藏）；任务聚焦模式下
  整页标题行本就隐藏，紧急求助随之隐藏与现状一致（聚焦任务有
  自身的紧急通道，不在本方案范围）。
- 验收：pytest 全量绿；截图对比（问诊进行中、关闭页、移动端）：
  品牌只出现在侧栏与消息头像，状态各只有一个出处，问题上方
  横条层数从 3 降到 0（标题行除外）。

## 风险

写入点删除须逐处核对上下文，避免误删同名逻辑；样式清理只限
卡头专属选择器。纯前端改动，独立分支，回退即还原。
